# Raja Vau Pro Tool - Cython Secure Version

This repository contains the advanced secure Cythonized version of **Raja Vau Pro Tool** (`Kamal.pyx`).

## Installation & Compilation Instructions

1. Install dependencies:
   ```bash
   pip install cython setuptools requests beautifulsoup4
   ```

2. Compile the Cython module:
   ```bash
   python setup.py build_ext --inplace
   ```

3. Run the tool:
   ```bash
   python main.py
   ```
